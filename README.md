# El cuarto de Clawd

Música hecha al momento en el navegador. Clawd produce en su cuarto y cada objeto que se toca cambia una parte de la canción. El cuarto guarda muchos secretos: búscalos.

Juégalo en https://lastrarteroth.github.io/cuarto-de-clawd/

Homenaje no oficial a Clawd, la mascota de Claude Code (Anthropic). Clawd y los personajes invitados que se cuelan en el cuarto son de sus dueños; ninguno es mío. Por Luis Lastra.

## Créditos

- Las muestras de instrumentos se grabaron desde [MuseScore General SoundFont](https://ftp.osuosl.org/pub/musescore/soundfont/MuseScore_General/), de S. Christian Collins, con licencia MIT.
- [Tone.js](https://tonejs.github.io/) (MIT) para el sonido y [three.js](https://threejs.org/) (MIT) para el cuarto en 3D.
